# Test Grid Images

Synthetic images used by instrumented tests to verify Ken Burns animation, panning, transitions, and framing without relying on real photos.

## Specifications

### Dimensions
Match actual camera output: **4080 × 1792** (landscape) and **1792 × 4080** (portrait).

### Grid layout
Each image is divided into a grid of cells. Every cell has:
- A distinct background color (hue evenly rotated across cells)
- A large bold cell number (readable at 1× scale from a 1080p screenshot)
- Small corner label with column letter + row index (e.g. `B2`)
- Center crosshair marker on the full image

### EXIF
All images carry GPS location tags so the app's date/location extraction code is exercised alongside the renderer.

## Files

| File | Dimensions | Cells | Purpose |
|------|-----------|-------|---------|
| `landscape_4080x1792.jpg` | 4080 × 1792 | 8 × 4 | Landscape photo — horizontal pan tests |
| `portrait_1792x4080.jpg` | 1792 × 4080 | 4 × 8 | Portrait photo — zoom rect tests |
| `square_2048x2048.jpg` | 2048 × 2048 | 4 × 4 | Square photo — edge-case aspect ratio |

## Usage

Load a grid image as a `TripSegment`, render a clip, extract a mid-point frame, and read the visible cell numbers to assert pan/zoom position and direction.

## Regenerating

Images are generated by `scripts/generate_test_grids.py`. Run from the repo root:

```bash
python3 scripts/generate_test_grids.py
```

Requires `Pillow` and `piexif`:

```bash
pip install Pillow piexif
```

Output files are JPEG (quality 95) for native EXIF support and smaller file size.
